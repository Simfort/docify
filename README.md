# Docify 📦✨

Turn your ZIP archives of JS files into clean, ready-to-use OpenAPI documentation—automatically.

## What it does

Docify simplifies API documentation by turning your code into structured OpenAPI specs:

- **Upload** a ZIP archive packed with JS files or just write your code.
- **Analyze** the code to extract functions, parameters, and metadata.
- **Generate** professional OpenAPI (Swagger) documentation in YAML/JSON.
- **Track & download** results via a simple task-based workflow.

Just send your ZIP—Docify handles the rest.

## Tech stack

Built for reliability and scalability:

- Next.js + Tailwind
- Node.js + Express
- TypeScript
- Prisma + PostgreSQL

## How to use

The service is already live at [docify-anaw.vercel](https://docify-anaw.vercel.app/)

1. Go to the upload endpoint.
2. Submit your ZIP archive or write your code.
3. Download or сopy the generated OpenAPI spec when ready.
